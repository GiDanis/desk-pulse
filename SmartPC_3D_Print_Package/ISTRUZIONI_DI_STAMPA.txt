SCHEDA TECNICA DI STAMPA 3D - CASE SMARTPC PER ORANGEPI ZERO 3W
====================================================================

Progetto: Case impilabile (99 x 72 x 25 mm) per OrangePi Zero 3W
Compatibile con: Dock/Schermo Hagibis 3.5" (B0D3CW311P)

FILE INCLUSI:
1. smartpc_base_style1_deluxe.stl  -> Base Stile 1 DELUXE (SE/30 Studio - Super Dettagliato, Frontale Pieno Scolpito, Prese Laterali Ergonomiche)
2. smartpc_base_style1_classic.stl -> Base Stile 1 CLASSIC (Mac SE Classico Pieno, 2 Feritoie Laterali Pulite)
3. smartpc_base_style2_quadra.stl  -> Base con frontale stile Mac Quadra Workstation
4. smartpc_base_style3_cyber.stl   -> Base con frontale stile Cyber-Retro
5. smartpc_lid.stl                 -> Coperchio superiore / vassoio di impilamento ad incastro per Hagibis

NOTA PER CHI STAMPA:
Per comporre il case completo serve STAMPARE:
- 1 x File Base (consigliato: "smartpc_base_style1_deluxe.stl" oppure "smartpc_base_style1_classic.stl")
- 1 x File Coperchio (smartpc_lid.stl)

PARAMETRI DI STAMPA FDM CONSIGLIATI:
--------------------------------------------------------------------
* MATERIALE: PETG o ABS / ASA (Consigliato).
  Motivazione: la scheda OrangePi Zero 3W monta un SoC Allwinner A733
  octa-core che sotto carico sviluppa calore. Il PETG o ABS garantiscono
  stabilità termica oltre i 70°C.
  (Se si usa PLA, preferire PLA+ o formulazioni ad alta tenacità termica).

* ORIENTAMENTO SUL PIATTO:
  - Base: appoggiata piatta sul fondo (nessuna rotazione necessaria).
  - Coperchio: stampare piatto con il lato superiore o inferiore a contatto col piatto.

* SUPPORTI: NESSUNO.
  I modelli sono stati disegnati con ponti e smussi a 45 gradi
  per stampare al 100% senza supporti.

* ALTEZZA STRATO (Layer Height):
  - 0.16 mm (raccomandato per massima definizione delle feritoie frontali)
  - 0.20 mm (ottimo compromesso)

* PERIMETRI (Walls): 4 o 5 perimetri (minimo 1.6 - 2.0 mm di spessore pieno).
* RIEMPIMENTO (Infill): 20% - 25% Gyroid o Grid.
* TOLLERANZE: Il modello include già 0.3 mm di gioco di accoppiamento.

FERRAMENTA DI MONTAGGIO FINALE (a cura del cliente):
--------------------------------------------------------------------
- 4x Viti M2.5 x 18 mm (a testa svasata) per fissare la scheda al dissipatore dal fondo.
- 4x Viti M2.5 x 20 mm (o autofilettanti) per chiudere il coperchio.
- 4x Gommini antiscivolo adesivi diametro 8-8.5 mm per il fondo.
