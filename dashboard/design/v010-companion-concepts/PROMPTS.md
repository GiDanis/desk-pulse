11 ottobre 2026. Generati con lo strumento integrato imagegen; quattro chiamate indipendenti. Anteprime statiche con dati demo, non asset animati né implementazione. ## Base comune

```text
Use case: ui-mockup.
Create ONE finished high-fidelity flat screenshot of the SmartPC Orange Pi companion dashboard, landscape 3:2 composition, logically designed at 960 x 640. It must fill the entire image edge to edge: no monitor, bezel, desk, perspective, poster frame, browser, or phone. This is a visual concept only, with sample data.
Identical functional layout for comparison between styles: top context bar 56px logical height, title "COMPAGNO" at left and clock "14:32" at right. Main scene occupies left 65% below header. Right 30% has three spacious need indicators with EXACT labels "Sazietà", "Energia", "Compagnia", short progress bars at roughly 70%, 45%, 80%, and one quieter progression row "Legame · Livello 2". The main scene contains ONE appealing tan puppy with floppy ears, a white chest patch and dark eyes, sitting attentively beside one small ball; a simple pet bed in the background. Full puppy visible, friendly coherent anatomy, not a human cartoon. Short state text "Vuole giocare". Bottom action strip contains FOUR readable choices: "Gioca", "Carezza", "Cibo", "Riposo"; only "Gioca" focused, shown with a clearly outlined accent border. Use large readable Italian sans-serif text, strong spacing, coherent margins, no tiny text, no permanent keypad legend, no extra menus or widgets. Keep the same logical content and main geometry across the concept variations. Dog personality, environment and UI should form one convincing finished product. Do not add logos, watermarks, brand names, flowers, toys beyond the single ball, or other characters.
```
